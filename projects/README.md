# Projets professionnels multi-fichiers

Ces deux projets sont les supports réels des activités `SPRING_BOOT-11/12` et `ANGULAR-09/10`.

- `spring-professional-api` : application Spring Boot avec contrôleur, service, modèle et test d'intégration MockMvc. Validation : `mvn test`.
- `angular-professional-dashboard` : application Angular standalone avec composant, template, styles, service et signals. Validation : `npm install`, puis `npm run build`.

Ils complètent les preuves unitaires exécutables du laboratoire : la preuve rapide valide l'invariant dans le runner isolé, tandis que ce workspace montre son intégration dans une véritable arborescence framework.
